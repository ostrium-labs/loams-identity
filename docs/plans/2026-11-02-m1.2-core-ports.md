**Goal:** Finish milestone M1.2: the I/O port traits of spec 01 §3 in `loams-identity-core`, their
simulated implementations in `loams-identity-sim`, and contract-test suites (ARCH-6) that the

## Review Focus

1. Concurrent use: a port shared through `Arc<dyn Port>` by many request handlers at once must
   work without a caller-side lock.
2. Secret leakage through `Debug` of nested request types (URL, headers, mail recipient).
3. Same seed, same output: two `SimKeyStore`s or `SeededRng`s from one seed produce identical
   bytes even when shared.
4. Clock jumps backwards must not resurrect expired cache entries.
5. Authorizer failures must deny, never allow.

### Task 1: Ports take `&self` and are `Send + Sync`

**Files:**
- Modify: `crates/core/src/ports.rs`
- Modify: `crates/core/src/contracts.rs`
- Modify: `crates/sim/src/basics.rs`, `crates/sim/src/keys.rs`, `crates/sim/src/services.rs`
- Modify: `crates/sim/tests/contracts.rs`

**Interfaces:**
- Produces: every port trait in `ports.rs` (`Clock`, `Rng`, `KeyStore`, `Cache`, `HttpClient`,
  `Mailer`, `EventSink`, `Authorizer`, `PasswordHasher`) is declared `pub trait X: Send + Sync`
  and every method takes `&self` (no `&mut self`). Later milestones hold ports as
  `Arc<dyn X>`. Contract functions take `&dyn X` (or `&impl X` where they do today).
  Method names, argument types and return types stay as they are.

- [ ] **Step 1: Write the failing test** in `crates/sim/tests/contracts.rs`:
  `ports_are_shareable` builds each fake once, wraps it in `std::sync::Arc<dyn Port>` for all nine
  ports, clones the `Arc`, and calls one method through each clone (for example
  `run(store.generate("i1", Algorithm::EdDsa))`, `rng.fill(&mut [0u8; 8])`). Add a second test
  `shared_seeded_rng_is_deterministic`: two `Arc<dyn Rng>` from seed `[7; 32]`, each filled 4 times
  with 16 bytes through two clones alternately; both byte sequences are equal.
- [ ] **Step 2: Run** `buildslot cargo test -p loams-identity-sim -j 4 --test contracts` — expect
  compile errors (`&mut self` methods cannot be called through `Arc<dyn …>`; traits are not
  `Sync`).
- [ ] **Step 3: Change the traits and fakes.** Fakes keep their state behind
  `std::sync::Mutex` and recover poisoned locks the way `SimClock::time` already does (no
  `unwrap`). Do not hold a lock guard across an `.await`; the fakes complete without awaiting, so
  lock, compute, unlock, then return `Box::pin(async move { result })`.
- [ ] **Step 4: Run** `buildslot cargo test -p loams-identity-sim -j 4` — all tests pass, the 16
  existing ones included.
- [ ] **Step 5: Commit** `core, sim: ports take &self and are Send + Sync (01 §3, ARCH-6)`.
